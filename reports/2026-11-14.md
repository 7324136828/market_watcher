**Method notes (so later runs compare like with like)**
- Z-score: trailing 20 daily closes **including** the current print, population σ. The first run used a
  different convention and printed larger magnitudes (e.g. DXY +3.29 vs +2.58 here); this convention is now
  fixed and documented in `data/README.md`.
- `us10y_change_48h_bps` is measured over the prior **two trading sessions**, skipping holidays.
- FMV: 10%-trimmed median of verified completions in the last 30 days, ≥3 comps required (§7.4), condition
  and grade tab matched exactly (§7.2). Fees assumed 13% for the deal-line arithmetic (§4.2/§7.3).
- **CSV schema reset:** the first run's `liquid.csv`, `illiquid.csv` and `prediction.csv` used a `date_utc`
  header. Per the export rules they were preserved as `liquid_v1.csv`, `illiquid_v1.csv` and
  `prediction_v1.csv`, and the current files start from the new `date` + `timestamp_utc` schema.
- **History backfill:** 90 days of daily closes (and derived 24h/5d/Z/volume-ratio metrics) for all 30 liquid
  assets, plus 2Y/10Y/30Y par yields and stablecoin supply, were backfilled into `timeseries.csv`,
  `liquid.csv` and `macro.csv` with `source` marked `backfill`, so charts start with 90 days of context
  rather than one point. `prices_wide.csv` now has 91 dated rows × 43 columns.
